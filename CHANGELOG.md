# Changelog

## 0.1.0 — 2026-11-03

- Despliegue sin registro por imágenes versionadas, paquetes privados y SSH estricto.
- Instalaciones Compose independientes de producción/demo, confirmación funcional,
  rollback reversible, recuperación automática y limpieza limitada por propietario.
- Docker de tres etapas, Python 3.12.16, UID 1000, 768 MiB y puerto interno 8000.
- Demo identificada y no indexable, sin geocodificación externa; pruebas de aislamiento.
- LICENSE corregido al texto AGPL v3 exacto; verificación HTTP de licencia obligatoria.
- Servidor MCP oficial 2.3.0 con cinco herramientas, modelos estrictos y salida estructurada.
- Swiss Ephemeris 2.10.03 / PySwissEph 2.10.3.2, datos fijados y sin fallback.
- Convención literal, incertidumbre explícita y manejo de geometrías de casas imposibles.
- Adaptador Nominatim configurable, desactivado por defecto.
- Límites de abuso, timeouts, logs técnicos y métricas sin datos natales.
- Pruebas, Docker, plantilla HTTPS/Compose, CI y oferta de código AGPL.
- Fuente del plugin 0.6.0 preparada; despliegue e integración real pendientes.
